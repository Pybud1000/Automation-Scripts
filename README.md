This repository contains the collection of automation scripts, pre-processing scripts and data analysis code I use for my Data Analyst work.
The codes are separated by the tool/technology I used, as well as the purpose.

**JavaScript** - I use JavaScript mainly to automate data collection and for web-scraping. Using libraries such as puppeteer to extract and collect the data I need from the web without the hassle of manual work
**Python** - I use Python snippets to manipulate, clean and process data sets. This is the primary tool I use at work relating to data Analysis, using libraries such as Pandas, NumPy, and MatPlotLib.
**VBA** - I use VBA macro for automating tasks/processes in excel files internally. Processes such as Automating the conversion of videos into links or OLE Objects stored within the excel file are some examples.
